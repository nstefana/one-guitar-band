# One Guitar Band

One Guitar Band is a real-time stand alone application that allows a guitarist to produce a full orchestration using only a standard electroacoustic or electric guitar.
The system incorporates several sound production functionalities, including that of a looper, and allows the user to access a single functionality at each repetition of the loop so as to gradually compose a more complete orchestration. Apart from guitar layers, the system offers
- drum production, by tapping the guitar in a certain way
- bass production, by playing a bass line of the first three strings of the guitar (from E1 to A2)
- modulation, by tapping the guitar or using a clock-based steppers
