# One Guitar Band

One Guitar Band is a real-time stand alone application that allows a guitarist to produce a full orchestration using only a standard electroacoustic or electric guitar.
The system incorporates several sound production functionalities, including that of a looper. The user controls a single functionality at each repetition of the loop so as to gradually compose a more complete orchestration. Apart from guitar layers, the user can add Drums and Bass elements. Particularly:
-  by tapping the guitar in a certain manner, the user can trigger drum samples (or cymbals) and arange them in time to compose the rhythmic part
- by playing a melodic line of the first three strings of the guitar (from E1 to A2), the user can program a bass line
- The sound of Drums and Bass can be customized to a large degree through various sound synthesis parameters and wavetables.
The system also includes different mechanisms with which the user can modulate the amplitude and frequency of a prerecorded guitar layer, so as to produce rhythmic and melodic patterns of unique sonic chatacter.
